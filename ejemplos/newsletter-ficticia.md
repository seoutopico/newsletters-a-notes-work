# Un resumen útil termina en una decisión

**Fuente ficticia creada para este repositorio.** Fecha ilustrativa: 13 de septiembre de 2026. Enlace de ejemplo: https://example.com/newsletters/resumen-que-ayuda-a-decidir

Pedir «resume esta reunión» puede producir un texto que cuente lo sucedido y deje intacta la pregunta de quien lo recibe: qué tiene que hacer ahora.

Antes de pedir el resumen, define tres cosas: quién lo leerá, qué decisión necesita tomar y qué datos no pueden perderse.

Imagina una reunión de seguimiento de un proyecto. Para alguien que se incorpora al equipo, puede ser útil explicar el contexto. Para la persona que debe desbloquear una entrega, importan el bloqueo, las alternativas y la decisión pendiente.

Prueba esta instrucción: «Resume la reunión para quien debe decidir cómo desbloquear la entrega. Separa lo acordado, lo pendiente de decidir y la información que falta. No inventes responsables ni fechas».

Al revisar la respuesta, comprueba que cada decisión mencionada aparece en la fuente y que una propuesta no se ha convertido en un acuerdo. Si no se sabe quién debe actuar, ese hueco debe permanecer visible.

La extensión viene después. Un texto breve puede seguir siendo poco útil si omite lo que permite decidir.
