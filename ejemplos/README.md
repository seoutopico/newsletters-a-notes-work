# Así pasa una newsletter a una Note

Puedes abrir estos tres documentos para ver qué obtendrás al utilizar el ejemplo:

1. [La newsletter de partida](newsletter-ficticia.md): el texto que Work leería como fuente.
2. [Una idea para recuperar](ideas-para-notes.md): qué merece convertirse en una Note y por qué puede interesar al lector.
3. [La Note para revisar](notes-para-revisar.md): el borrador, separado del comentario editorial que explica la elección.

Esta muestra contiene una idea y una Note para facilitar la comparación. La petición habitual busca cinco ideas y tres Notes. Los archivos con extensión `.md` son documentos de texto; puedes leerlos aquí mismo en GitHub o abrirlos en Work.

**Todo el material de esta muestra es ficticio.** No procede de las newsletters de Aina Lluna y no representa una descarga o una ejecución real. El enlace de `example.com` es ilustrativo.

Para crear tus propios resultados, vuelve a [la guía desde cero](../README.md#usarlo-desde-chatgpt-work). Work guardará las nuevas propuestas en las carpetas de tus tandas; esta carpeta solo contiene la muestra.
