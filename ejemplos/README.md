# Ejemplo editorial ficticio

Estos tres archivos ilustran el relevo entre etapas. Son material inventado para explicar el formato: no proceden de la biblioteca de Aina, no atribuyen experiencias a una persona real y no son una ejecución del flujo.

1. [Fuente ficticia](newsletter-ficticia.md).
2. [Idea derivada](ideas-para-notes.md).
3. [Note para revisar](notes-para-revisar.md).

La muestra contiene una sola idea y una Note para facilitar la comparación. El flujo habitual prepara cinco ideas y tres Notes. El enlace de `example.com` es un marcador ilustrativo y debe sustituirse por el enlace real antes de publicar cualquier adaptación.

No se incluye un `estado.json` simulado: estos documentos no deben entrar en el historial de tandas reales ni contar como trabajo completado.
